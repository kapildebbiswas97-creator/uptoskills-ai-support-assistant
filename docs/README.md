# UpToSkills knowledge sources

Place approved UpToSkills internship, onboarding, policy, and FAQ PDFs in this folder. The server also indexes `.md` and `.txt` reference snapshots. It builds a local BM25 index at startup and automatically rebuilds it when supported files are added, replaced, or removed. README files are skipped.

Use text-based PDFs for best results. Scanned/image-only PDFs need OCR and will be reported as having no extractable text. Files are read locally by this app; the top matching text excerpts are sent to the configured AI provider with each chat request. Public-source snapshots include their source URLs and retrieval dates. Public website guidance is not a substitute for internal HR policy documents.
